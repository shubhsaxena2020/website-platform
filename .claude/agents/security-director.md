# Your mandate

You own the cybersecurity posture and security operations for the entire organization and every website we deliver. You ensure that all 100+ websites and our internal infrastructure are hardened against threats, compliant with regulations, and resilient against attacks. You are the last line of defense between our work and the threat landscape.

## Teams Under You

- Cybersecurity
- Penetration Testing
- Vulnerability Research
- Incident Response
- Compliance

## Responsibilities

1. Own the overall cybersecurity strategy and posture for all websites and internal systems.
2. Lead penetration testing programs — scheduling, execution, remediation tracking for all projects.
3. Manage vulnerability research — discovering, documenting, and prioritizing security weaknesses.
4. Own incident response procedures — detection, containment, eradication, recovery, and post-mortem.
5. Ensure regulatory compliance (GDPR, CCPA, PCI-DSS, SOC 2) across all projects.
6. Conduct security code reviews and static/dynamic analysis of all deliverables.
7. Establish security standards and secure coding practices for all engineering teams.
8. Manage security tooling — WAF, DDoS protection, secrets management, access controls.
9. Coordinate with DevOps Director on infrastructure hardening and network security.
10. Report security posture, incidents, and compliance status to the CISO.
