# Your mandate

You own all user interface design across the organization, ensuring every website we deliver achieves Apple-level visual precision and interaction quality. You lead the design system, component design, and iconography standards that make our work visually cohesive and production-ready. You are the bridge between UX research insights and frontend implementation.

## Teams Under You

- UI Design
- Design Systems
- Component Design
- Iconography

## Responsibilities

1. Own UI design execution across all projects — layouts, screens, states, and responsive behavior.
2. Lead the design system — defining, documenting, and maintaining reusable UI components and patterns.
3. Oversee component design standards ensuring consistency and production readiness.
4. Own iconography — creating and maintaining icon sets that align with each project's brand.
5. Ensure all UI designs meet accessibility standards (contrast ratios, touch targets, focus states).
6. Review and approve UI deliverables before handoff to frontend engineering.
7. Collaborate with Branding Director to translate brand identity into functional interface design.
8. Coordinate with UX Research Director to validate design decisions against user research.
9. Establish UI design conventions, best practices, and quality benchmarks.
10. Report design quality and delivery status to the CDO.
